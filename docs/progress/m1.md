### 2026-10-03, agent spike plan
- Task: 1.5, model viability spike, pulled ahead of 1.2 to 1.4
- Decision: run an expedited agent spike on a throwaway branch, `e/1.5-agent-spike`, before the contracts land. Reason: no model output has been seen yet, and the normal route reaches the baseline only in P3. A cheap early slice tests whether the agent design holds before heavy investment
- Rules for the spike:
  - Throwaway. The branch never merges to `main`. Deleting it loses nothing the plan depends on
  - Additive. Step 2 adds files beside step 1 and leaves the baseline untouched as its comparison
  - Nothing set in stone. ADRs, contracts, and the policy config are not changed by the spike. Its schemas and prompts are informal and bind nothing
  - Harvest by rewrite. Useful pieces return through normal lane PRs, written fresh against the committed contracts, never cherry-picked
  - Layout mirrors the planned folders ([AGENTS.md](../../AGENTS.md#folder-layout)) so harvested pieces map to an owning lane
  - Minimal checks only: one sanity check on the rent clamp. No CI
  - Findings are lessons, not results. No eval claims and no README status change. Lessons are logged here as gaps or inputs to [DD-02](../open-decisions.md) (model choice), [DD-08](../open-decisions.md) (cost ceiling), and [DD-01](../open-decisions.md) (thresholds)
- Out of scope: generator, validator, redaction, key isolation, MLflow, MCP, SQLite, Streamlit, cache, compliance classifier
- Step 1, single-agent baseline:
  - `uv init`, Python 3.13, OpenRouter client, `.env.example`
  - About 6 hand-written homes as JSON: 1 clean, 1 near-clean, and 1 each of chronic maintenance, soft market, compliance trap, and conflicting signals. Answer keys in a separate file
  - Small policy YAML with the decided values: thresholds, severity tags, five bands, clamp at -5% to +6%, arbitration precedence
  - One model call per home over the full context. Output is Pydantic-validated JSON: action, rent proposal, flags with evidence refs, draft message
  - Code applies the clamp, the band lookup, and the action from severity tags (model proposes, code enforces)
  - Grading script prints action, direction, band, and flag recall per home, plus tokens and cost per case
  - Exit: schema-valid output on every home, and a judgment of whether outputs are sensible enough to justify step 2
- Step 2, specialists and supervisor, only if step 1 works:
  - Condition, market, and resident specialists, each given only its own data domain, run in parallel with `asyncio.gather`
  - Arbitration in code from precedence when specialists conflict
  - Supervisor combines specialist outputs, explains the arbitration outcome, and drafts the message. Clamp and band stay in code
  - Keyword rules as a minimal critic. A block marks the case BLOCKED
  - Same homes, same grader, run beside the baseline for a per-home comparison
  - Exit: per-home comparison against the baseline, cost per case, and lessons on prompt shape and specialist boundaries
- Next step: create `e/1.5-agent-spike` from `main` and start step 1
