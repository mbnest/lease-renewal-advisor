# Security policy

Status: living policy. Last updated 2026-10-03.
How to report a security concern in this repository.

## Supported versions
- None. Nothing is released and nothing runs yet. Reports apply to the `main` branch

## Reporting a vulnerability
- Do not open a public issue
- Report privately through GitHub: [report a vulnerability](https://github.com/mbnest/lease-renewal-advisor/security/advisories/new). This uses GitHub private vulnerability reporting, which is enabled for this repo
- Include what you found, where, and how to reproduce it

## What counts
- A committed key, token, or credential
- A path that lets a model, span, or trace see a protected-characteristic field before redaction
- A path that lets an agent read the answer keys
- A path that lets the system send a message or change a rent. It only recommends and records

## What does not
- All data is synthetic and fictional. A fictional name or address in the data is not a data leak
- Usage questions and non-security bugs go to [issues](https://github.com/mbnest/lease-renewal-advisor/issues)

## Known gaps and open questions
- No response time is committed
